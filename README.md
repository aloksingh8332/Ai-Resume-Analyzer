# 🤖 AI Resume Analyzer

An AI-powered resume analysis platform that helps job seekers understand their resume, compare it with job descriptions, and identify areas for improvement.

## 🚀 Features

- 📄 Resume analysis
- 🎯 Job description matching
- 📊 Resume/Job compatibility scoring
- 💡 AI-powered feedback
- 📈 Skill gap analysis
- 🛠️ Resume improvement suggestions

## 🛠️ Technologies Used

### Frontend
- React 19
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Python
- FastAPI
- Uvicorn

### AI & Processing
- Google Gemini API
- PyPDF2
- Pydantic

## 📌 Project Overview

The AI Resume Analyzer analyzes a candidate's resume and provides useful insights based on the provided job description.

It helps users identify relevant skills, understand potential gaps, and improve their resume for better job opportunities.
